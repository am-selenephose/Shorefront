# Shorefront local webfonts

Unmodified Latin WOFF2 subsets downloaded on 2026-10-02 from Google Fonts.
No Google Fonts request is needed while using the application. Glyphs outside
these subsets use the declared system fallback; this is not multilingual coverage.

Space Grotesk is designed by Florian Karsten and based on Space Mono.
Space Mono is by Colophon Foundry. Both retain their SIL Open Font Licence 1.1
and copyright notices in the adjacent `*-OFL.txt` files.

Upstream: https://github.com/floriankarsten/space-grotesk and
https://github.com/googlefonts/spacemono.
