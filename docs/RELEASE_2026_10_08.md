## New real operational features

1. Authenticated Readiness control workspace backed by GET /api/v1/readiness:
   active recorded calls, record-source provenance, absent berth coordinates,
   dimensional coverage, unresolved incidents and coordination, port resource
   availability and actual schedule conflicts. Unknown data remains unknown.
2. Read-only berth/time scenario lab backed by POST /api/v1/plan/what-if:
   compare recorded current berth and UTC interval with a proposed alternative
   and surface added conflicts and time changes. API checks authentication,
   exact origin, CSRF, existing calls/berths, ordered times, same-port berth
   boundaries and non-closed calls. No record writes or external actuation.
3. Responsive light/dark operational panels. These workspaces are part of
   the authenticated customer product, not just the static public showcase.
4. Independent disposable integration browser suite for these features, so
   its test accounts cannot conflict with the existing product test fixtures.
5. Market capability/gap review in COMPETITOR_CAPABILITY_AUDIT_2026_10_08.md.
