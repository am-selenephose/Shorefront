## Product convergence delivered

Pulse remains map-first. The release adds a single integrated operating deck
rather than replacing the geographic canvas with dashboard chrome.

The operating deck provides:

- source-aware vessel/call lineup with search and operational lenses;
- recorded resource availability lanes;
- a 6H / 24H / ALL two-clock event scrubber;
- an operator decision lane derived from recorded incidents, conflicts,
  coordination state, berth assignment and resource state;
- persistent selected-call context across map, runway, berth horizon and lineup;
- explicit human authority and no automatic vessel or terminal actuation path.

Closed work no longer remains in the active Pulse event context. Its durable
lineage remains in Evidence and History.

## Operations and recovery

The existing operational health and backup automation is enabled on the host:

- health verification timer: every five minutes;
- daily PostgreSQL backup timer;
- user service linger enabled so timers survive logout;
- public /metrics remains hidden;
- internal API metrics remain available to the private service network.

The latest scheduled backup checksum passed. That exact backup restored into a
disposable PostgreSQL 17 instance. Every current sf_* table was present and the
row count of all 15 tables exactly matched the live read-only count.

This proves recoverability of that captured backup in an isolated rehearsal. It
does not prove a customer RTO/RPO, off-site durability, backup encryption policy
or disaster recovery under production load.

## Claim boundaries and remaining release gates

Shorefront still does not claim:

- live AIS, weather, tides, UKC or terminal truth without a contracted source;
- full DCSA certification; current support remains an explicit subset;
- autonomous vessel or terminal control;
- external signed timestamps or third-party cryptographic attestation;
- calibrated optimization, causal savings or a historical counterfactual twin;
- enterprise SSO/federated identity;
- multi-host high availability or a commercial SLA;
- independent security approval or capacity qualification;
- completed customer acceptance or a paid production workflow.
