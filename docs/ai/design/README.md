# Shorefront decision workspace design

The Python simulator remains the semantic authority. React presents snapshots,
risks, dependencies and recovery proposals; it does not duplicate simulation.

Read-only comparison clones the current harbor, projects actions on sink-free
simulators and returns full projected timelines. Guided demo builds a fresh,
sink-free scenario independent of the live store. Its synthetic receipt cannot
be confused with an authenticated operational receipt. Neither API writes to the
live ledger or modifies the active harbor.

Workspace location is a URL hash with validated routes. The optional full control
tower preserves advanced inspection while Pulse is the default. Presentation role
lenses never change operator credentials. Architecture mode reports implemented
components and unimplemented gates distinctly.

Client snapshot transport owns fetch deadlines, websocket lifecycle, reconnect
timer cleanup and freshness. Mutation controls are unavailable with stale data.
Palette tokens and bundled fonts stay canonical; new surfaces reuse them.

Historical replay requires versioned facts with valid and knowledge time, not
filtering descriptive event strings. Standards adapters sit outside domain rules.
External v1 consumers and old evidence must retain deliberate compatibility until
a separately tested new version and migration exist.
