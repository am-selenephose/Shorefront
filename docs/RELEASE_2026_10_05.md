## Record conflict recovery

The latest recorded revision is the optimistic-write precondition. It can differ
from the current effective fact when a revision is scheduled or backdated. A
normal workspace refresh therefore cannot always resolve an edit conflict.

- Authenticated `GET /api/v1/records/{kind}/{record_id}/head` returns the highest
  recorded revision without changing the effective/knowledge-time snapshot.
- A conflict retains the draft. Review shows the latest payload, source and both
  timestamps; replacement requires an explicit action and saving a separate one.
- Saving after review uses the new revision, a fresh idempotency intent and the
  existing server-side authority/validation path. A concurrent write still causes
  a conflict. Review does not reserve or lock the record for later submission.
- The UI explains that a correction takes effect now; existing future versions
  remain in history and can become effective at their scheduled time.
- A recorded relationship absent from current choices remains selected with an
  explicit unavailable label. It is not silently converted to an empty value.
  Server validation can reject it; the operator must deliberately change/clear
  the relationship if the correction should take effect now.
- No database migration, schema change, customer-data seed, temporal policy
  rewrite or relaxation of authentication/role/CSRF checks is included.

## Remaining gates

- `production_ready` remains false. The current HTTPS address is a Cloudflare
  quick tunnel to this machine, not durable customer hosting or an uptime SLA.
- Stable customer hosting/origin, backup retention/automation, monitoring,
  independent security review, cross-engine/load/accessibility acceptance and
  customer workflow validation remain unqualified.
- Planning is deterministic and advisory with explicit human approval, not a
  completed autonomous multi-agent system. No physical execution or clearance.
- Federated partner identity/field projections, standards-conformant live feeds
  and SDK/registry, semantic reconciliation, external signed evidence,
  counterproposal chains, historical counterfactual twins and calibrated outcome
  learning remain unfinished. Observed outcomes are not causal savings proof.
- The generic-editor fix does not implement scheduled-edit management or change
  decision-approval temporal policy. Unavailable references fail closed until
  deliberately resolved. Historical decision navigation remains bounded.
- Existing training-map chunk-size and dependency deprecation warnings remain.
